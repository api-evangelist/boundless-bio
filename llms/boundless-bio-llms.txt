# Boundless Bio

> Boundless Bio (Nasdaq: BOLD) is a San Diego, California based clinical-stage, next-generation
> precision oncology company founded in 2018 to target extrachromosomal DNA (ecDNA) — circular,
> centromere-free DNA that carries high copy-number oncogene amplifications, observed in roughly
> 17% of cancer patients, and a driver of tumor heterogeneity and resistance to targeted therapy.
> Its Spyglass discovery platform identifies targets essential to ecDNA function, which the company
> drugs with small-molecule ecDNA-directed therapies (ecDTx). The clinical pipeline is led by
> BBI-940, a kinesin inhibitor targeting ecDNA segregation, in the Phase 1 KOMODO-1 trial in
> ER+/HER2- and TNBC-LAR breast cancer opened in February 2026, with CHK1 (replication stress) and
> RNR (DNA assembly and repair) programs behind it. ECHO, its ecDNA diagnostic algorithm, reads
> ecDNA off routine clinical next-generation sequencing. Boundless Bio runs NO developer program and
> publishes NO product API, developer portal, API documentation or SDKs. The only machine-readable
> surface reachable without credentials is the WordPress REST content API behind boundlessbio.com,
> described below.

## What an agent can actually do here

There is one API: a read-only WordPress REST content API. It requires no credentials. It serves the
company's leadership directory, corporate pages and media library. It does NOT expose clinical trial
data, pipeline data, patient data, ecDNA sequencing data, or anything about BBI-940, ECHO or
Spyglass beyond what is written in the public page copy.

Base URL: https://boundlessbio.com/wp-json

- [REST API index](https://boundlessbio.com/wp-json/): 219 routes across 10 namespaces; the
  authoritative live route table.
- [Leadership](https://boundlessbio.com/wp-json/wp/v2/who-we-are): 27 published records — executive
  team, board of directors and scientific / clinical advisors. Full biographies, job titles and
  LinkedIn URLs. The single highest-value collection.
- [Pages](https://boundlessbio.com/wp-json/wp/v2/pages): 9 corporate pages.
- [Media](https://boundlessbio.com/wp-json/wp/v2/media): 255 attachments — including the scientific
  conference posters, stored as PDFs.
- [Categories](https://boundlessbio.com/wp-json/wp/v2/categories): Board of Directors (4),
  Leadership (4), Scientific / Clinical Advisors (5), Uncategorized (0).
- [Search](https://boundlessbio.com/wp-json/wp/v2/search?search=ecDNA): cross-content search.
- [oEmbed](https://boundlessbio.com/wp-json/oembed/1.0/embed): oEmbed 1.0 provider endpoint.

Conventions: page/per_page pagination (per_page max 100), X-WP-Total and X-WP-TotalPages response
headers, RFC 8288 Link header for next/prev, `_fields` to trim the payload, `_embed` to inline
related objects. Errors are the WordPress envelope `{code, message, data:{status}}` — NOT RFC 9457.
No rate-limit headers; robots.txt asks for a 10-second crawl delay site-wide. Responses carry a
10-minute edge TTL behind Cloudflare and WP Engine.

## Two traps on this specific deployment

1. **Page bodies are empty on `content`.** `content.rendered` and `excerpt.rendered` are empty
   strings on all 9 pages. The real page copy is served in the public `acf.modules` array (Advanced
   Custom Fields flexible content), one entry per layout block. Read `acf`, not `content`. The
   `who-we-are` Leadership type is the exception — its `content.rendered` is populated normally.
2. **The category taxonomy covers only half the team.** 14 of the 27 Leadership records return
   `categories: []`. Filtering Leadership by category silently drops them. Use the job title in
   `acf.title` instead. Also note the advisors term's slug (`scientific-founders`) does not match
   its display name (`Scientific / Clinical Advisors`).

## What is gated — do not assume otherwise

- `/wp/v2/settings` → 401 `rest_forbidden`.
- `/wp-json/wp-abilities/v1/*` → 401. The WordPress Abilities API is registered and entirely gated.
- `/wp-json/mcp` → 404 `rest_no_route`. There is **no MCP server** on this site.
- `/wp/v2/global/search` → HTTP 500 with `{"code":"front_end_ajax_search","message":"No results",
  "data":null}` when a query has no matches. A theme AJAX route, not part of `wp/v2`.
- Every write route (POST/PUT/PATCH/DELETE) requires an authenticated WordPress user.

## Not published

No OpenAPI. No AsyncAPI, webhooks or event surface. No GraphQL. No MCP server. No agent card at
`/.well-known/agent-card.json` or `/.well-known/agent.json` (both 404 on the apex and www). No SDKs,
packages or CLI, and no GitHub organization. No `/.well-known/security.txt`, `openid-configuration`,
`oauth-authorization-server`, `oauth-protected-resource`, `api-catalog` or `ai-plugin.json` (all
404). No status page, SLA, changelog, deprecation policy, pricing, sign-up or developer support
channel. No trust center and no published compliance certification. No blog — the `post` collection
is empty and `/feed/` returns zero items.
